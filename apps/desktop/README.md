# NextMux desktop

The Windows/macOS application is composed with Eclipse Theia and Electron. The
custom NextMux extension owns the customer-facing Model Center, coding and
comic workbenches, settings, route strip, and account experience. Theia remains
the underlying editor, terminal, workspace, language, Git, Skills, MCP, and
extension host.

This package is not a browser deployment.

```powershell
pnpm desktop:build
pnpm desktop:start
```
