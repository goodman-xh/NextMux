# Code Signing Policy

## Free Code Signing for Windows

Free code signing on Windows is provided by [SignPath.io](https://signpath.io/), and the certificate is issued by the [SignPath Foundation](https://signpath.org/).

## Roles and Approvers

- **Committers and Reviewers**: Core maintainers of the NextMux Desktop Open-Source Client repository.
- **Approvers**: Release maintainers of NextMux (`Xinwoteam1@gmail.com`).

## Privacy Policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Official Windows release pipelines (`win32-x64` and `win32-arm64`) are configured to integrate with SignPath.io for deterministic CI builds and Authenticode signing upon SignPath Foundation project onboarding.
