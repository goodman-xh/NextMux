# Direct-provider logo assets

These bundled SVGs come from the open-source [Lobe Icons](https://github.com/lobehub/lobe-icons) collection. Provider-company marks added or refreshed in this directory use `@lobehub/icons-static-svg` version `1.95.0`; the remaining files use the same static-SVG format.

The direct-API grid identifies the API destination, so cloud-hosted model families use the platform mark: Alibaba Cloud Model Studio, Baidu AI Cloud, Volcano Engine and Tencent Cloud. OpenAI has one official entry; ChatGPT is not presented as a separate API provider.
