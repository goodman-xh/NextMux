# Security policy

## Supported versions

NextMux is currently an alpha. Security fixes are applied to the latest
development branch and the newest tagged alpha only.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for the repository. Do not open a
public issue or include live credentials, merchant secrets, customer data, or a
working exploit in a public discussion.

Include the affected component and version, reproducible steps, impact, and any
suggested mitigation. Maintainers should acknowledge a complete report within
three business days, keep the reporter informed during triage, and coordinate a
fix and disclosure date before publishing details.

Immediately revoke any real credential accidentally committed to a branch or
artifact. Removing it from Git history is not a substitute for revocation.
